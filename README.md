A Python based discord bot for simplifying workflows like deleting messages, sending DMs & webhooks, creating threads and more...

# Getting started
1. Clone or download this repository.
    ```sh
    git clone https://github.com/MrParindiyal/chadbot.git
    cd chadbot
    ```
2. Install uv \
   https://github.com/astral-sh/uv

3. Run the main script
    ```sh
    ./run.sh
    ```
